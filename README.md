# Personal site

Static site, no build step: `index.html`, `style.css`, `assets/`.

## Deploy to GitHub Pages
1. Create a public repo named exactly `amirosko.github.io`.
2. Copy these files into it, commit, push to `main`.
3. Repo → Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Live at `https://amirosko.github.io` in a minute or two.
